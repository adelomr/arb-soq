# سياسة الخصوصية - SMS Gateway Pro

## استخدام الصلاحيات

### صلاحيات SMS
تطبيق SMS Gateway Pro يستخدم الصلاحيات التالية **للوظائف الأساسية فقط**:

- **SEND_SMS**: لإرسال رسائل SMS عبر API
- **READ_SMS**: لقراءة الرسائل الواردة (اختياري)
- **RECEIVE_SMS**: لاستقبال الرسائل الواردة (اختياري)
- **READ_PHONE_STATE**: للتحقق من حالة الشريحة

### الغرض من الاستخدام
هذه الصلاحيات تستخدم **فقط** لـ:
1. إرسال رسائل SMS بناءً على طلبات API
2. التحقق من حالة الشريحة
3. تسجيل الرسائل المرسلة في قاعدة البيانات المحلية

### ما لا نستخدمه
- **لا نستخدم** هذه الصلاحيات للإعلانات
- **لا نستخدم** هذه الصلاحيات لتتبع المستخدمين
- **لا نستخدم** هذه الصلاحيات لجمع البيانات الشخصية
- **لا نستخدم** هذه الصلاحيات لأغراض غير أساسية

### حماية البيانات
- جميع البيانات محفوظة محلياً على الجهاز
- لا يتم إرسال أي بيانات شخصية إلى خوادم خارجية
- يمكن للمستخدم حذف جميع البيانات في أي وقت

### الامتثال لسياسات Google Play
هذا التطبيق يلتزم بسياسات Google Play Store:
- الصلاحيات تستخدم للوظائف الأساسية فقط
- لا توجد إعلانات أو تتبع
- الوظيفة الأساسية هي إرسال SMS عبر API
