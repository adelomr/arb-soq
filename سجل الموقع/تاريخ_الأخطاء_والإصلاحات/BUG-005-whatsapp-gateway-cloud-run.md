# BUG-005: حل مشكلة تعذر إرسال كود التفعيل بعد النشر (Fetch Failed - WhatsApp Gateway)

التاريخ: 2026-08-27

المشكلة:
ظهور رسالة خطأ "تعذر إرسال الرمز - fetch failed" عند محاولة إرسال كود التحقق (OTP) أو رسائل التفعيل عبر واتساب في صفحة الملف الشخصي `/profile` بعد نشر الموقع على الإنترنت.

السبب:
1. **اعتماد النظام على خادم محلي:** كان تطبيق Next.js مهيأً افتراضياً للاتصال بسيرفر بوابة واتساب على `http://localhost:5005` والذي يعمل فقط على جهاز المطور محلياً.
2. **غياب السيرفر في بيئة السحابة:** عند نشر الموقع على السيرفر (Firebase Hosting / Cloud Run)، لا يمكن لدوال السيرفر الوصول لـ `localhost:5005` المحلي، مما ينتج خطأ `TypeError: fetch failed (ECONNREFUSED)`.
3. **رسائل خطأ غامضة:** عند حدوث خطأ الاتصال، كان الكود يرجع النص التقني `fetch failed` للمستخدم دون توضيح السبب أو الإرشاد لحل المشكلة.

الحل:
1. **نشر بوابة واتساب على Google Cloud Run:**
   - إنشاء ملف `whatsapp-gateway/Dockerfile` و `whatsapp-gateway/.dockerignore` لتجهيز بيئة حاوية Docker خفيفة بنظام `node:20-slim`.
   - نشر الخدمة على Google Cloud Run باسم `whatsapp-gateway` في المنطقة `europe-west1` وضبط `Min instances = 1` و `Max instances = 1` لضمان بقاء جلسة واتساب تعمل باستمرار 24/7 دون نوم.
   - ربط رقم واتساب الخاص بالموقع (`+201003975823`) عبر مسح الـ QR Code من رابط الخدمة السحابية.
2. **تحديث عنوان البوابة السحابية في الكود وملفات البيئة:**
   - تحديث `src/lib/whatsapp-gateway-client.ts` ليعتمد تلقائياً على الرابط السحابي `https://whatsapp-gateway-264703833176.europe-west1.run.app` كنقطة اتصال افتراضية.
   - إضافة المتغير `WHATSAPP_GATEWAY_URL` في ملفات `.env.production` و `.env.local`.
3. **تحسين معالجة الأخطاء:**
   - تحسين دوال `sendWhatsAppOTP` و `sendWhatsAppMessage` لعرض رسائل خطأ عربية واضحة ومفهومة للمستخدم والإدارة في حال انقطاع البوابة أو الحاجة لمسح الـ QR.

الملفات المتأثرة:
- `whatsapp-gateway/Dockerfile` [جديد]
- `whatsapp-gateway/.dockerignore` [جديد]
- `src/lib/whatsapp-gateway-client.ts`
- `.env.production`
- `.env.local`
- `CHANGELOG.md`
- `PROJECT_MEMORY/CHANGELOG.md`

الاختبار:
- فحص حالة الخادم السحابي عبر نقطة `/status` والتأكد من إرجاع `connected: true` ورقم الهاتف `201003975823`.
- تجربة إرسال كود التفعيل من الموقع واستلام الرسالة المنسقة بنجاح على تطبيق واتساب.

منع التكرار:
- خادم البوابة يعمل الآن بشكل دائم (`Min Instances = 1`) على Cloud Run.
- عند الرغبة في إعادة ربط الحساب، يمكن زيارة الرابط السحابي `/qr` ومسح الكود مباشرة دون الحاجة لتشغيل أي خادم محلي.
