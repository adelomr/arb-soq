# 📱 Arb-Soq WhatsApp Web Gateway

خادم بوابة واتساب المستقل الخاص بموقع **سوق العرب** لإرسال أكواد التحقق (OTP) وإشعارات الاشتراكات والعمليات فورياً وبشكل مجاني.

---

## 🚀 تشغيل البوابة (Quick Start):

1. **تثبيت الحزم (مرة واحدة):**
   ```bash
   cd whatsapp-gateway
   npm install
   ```

2. **بدء الخادم:**
   ```bash
   npm start
   ```

3. **ربط الحساب:**
   - افتح المتصفح على: `http://localhost:5005/qr`
   - افتح تطبيق **WhatsApp Business** على هاتفك.
   - اذهب إلى: **الإعدادات > الأجهزة المرتبطة > ربط جهاز** وامسح الرمز.

---

## 📡 واجهات الـ REST API:

- `GET /status` — فحص حالة الاتصال ورقم الهاتف المتصل.
- `GET /qr` — عرض صفحة ويب تفاعلية لمسح رمز الـ QR.
- `POST /send-message` — إرسال رسالة نصية لأي رقم هاتف:
  ```json
  { "phone": "010xxxxxxxx", "message": "نص الرسالة" }
  ```
- `POST /send-otp` — إرسال كود تفعيل 6 أرقام منسق باسم سوق العرب:
  ```json
  { "phone": "010xxxxxxxx", "code": "839201" }
  ```
