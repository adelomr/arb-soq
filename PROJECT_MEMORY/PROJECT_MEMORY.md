# PROJECT MEMORY

## هدف المشروع
يعد هذا الملف المرجع الرئيسي للمشروع. يجب قراءته قبل أي تعديل.

## قاعدة إلزامية

لا تعتبر أي مهمة مكتملة إلا بعد تحديث سجل المشروع.

يجب بعد كل تعديل:

1. تحديث CHANGELOG.md.
2. توثيق أي خطأ تم إصلاحه.
3. توثيق أي قرار هندسي جديد.
4. تحديث ARCHITECTURE.md إذا تغيرت بنية المشروع.
5. تحديث أي ملفات أخرى متأثرة.

إذا لم يتم تحديث سجل المشروع، تعتبر المهمة غير مكتملة.

## قاعدة قبل التنفيذ

قبل إجراء أي تعديل يجب:
1. قراءة PROJECT_MEMORY.md بالكامل.
2. مراجعة PROJECT_RULES.md.
3. مراجعة DATABASE_SCHEMA.md للتأكد من عدم كسر التوافق مع تطبيق الأندرويد.
4. مراجعة CHANGELOG.md.
5. مراجعة bug-history.
6. فهم تأثير التعديل على المشروع.

بعد الانتهاء:
- تحديث سجل المشروع.
- مراجعة الملفات المتأثرة.
- التأكد من عدم كسر أي ميزة.
