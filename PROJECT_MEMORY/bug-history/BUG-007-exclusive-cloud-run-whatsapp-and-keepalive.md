# BUG-007: حصر بوابة واتساب سحابياً على Google Cloud Run وتفعيل التنشيط التلقائي وصيغة النسخ السريع

التاريخ: 2026-08-29

## 1. المشكلة وسياق التعديل:
1. **الاعتماد السابق على هاتف محلي ونفق مؤقت:** كان النظام يتطلب إبقاء هاتف الأندرويد متصلاً بالإنترنت وشاشته مفتوحة، بالإضافة لتشغيل نفق Cloudflare Tunnel من الكمبيوتر، مما كان يسبب انقطاع الخدمة عند إغلاق الهاتف أو انتهاء رابط النفق.
2. **سقوط الجلسة السحابية في الخمول:** سيرفر Google Cloud Run كان يدخل في وضع النوم (Scale-to-Zero) عند انقطاع الطلبات.
3. **تشتت مسارات الإرسال:** وجود مسارات احتياطية متعددة (Fallback) تحول الطلبات لهاتف البوابة بدلاً من السحابة.

## 2. الإجراءات والحلول المطبقة:
1. **حصر الإرسال على Google Cloud Run بنسبة 100%:**
   - حذف كافة مسارات الهاتف المحلي (`192.168.1.4:8088`) ونفق كلاودفلير من كود الموقع.
   - جعل السيرفر السحابي `https://whatsapp-gateway-264703833176.europe-west1.run.app` هو الوجهة الحصرية والوحيدة في `src/lib/whatsapp-gateway-client.ts`.
2. **تفعيل مسار التنشيط السحابي 24/7 (Keep-Alive Cron):**
   - إنشاء مسار `src/app/api/cron/whatsapp-keepalive/route.ts` لفحص وإيقاظ السيرفر السحابي بانتظام دون أي خمول.
3. **تنسيق كود التحقق OTP لسهولة النسخ:**
   - تغليف الأكواد داخل علامات Monospace (` ```123456``` `) لتمكين المستخدم من نسخ الرمز بنقرة واحدة داخل واتساب دون نسخ النصوص المجاورة.
4. **تنظيف واجهة المستخدم:**
   - إخفاء لوحة سجل التشخيص في الموقع المنشور وقصرها على بيئة التطوير المحلية (`localhost`).

## 3. الملفات المتأثرة:
- `src/lib/whatsapp-gateway-client.ts`
- `src/app/api/cron/whatsapp-keepalive/route.ts`
- `src/components/ProfileForm.tsx`

- `CHANGELOG.md`
- `PROJECT_MEMORY/CHANGELOG.md`

## 4. نتيجة التحقق والاختبار:
- فحص استجابة السيرفر السحابي من الموقع الحي:
  `{"status":"connected","connected":true,"phone":"201003975823"}`
- تجربة إرسال كود OTP واستلامه بنجاح فوري مع مربع النسخ المباشر.
